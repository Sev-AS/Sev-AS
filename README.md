## What I do

I build automations that **fail safely and report their own errors**. Most flows are built for the happy path — mine run in production with structured error handling (Try/Catch patterns), alert the right person on Teams when something breaks, and process bulk data without losing a single row.

- **Power Automate (Cloud) at Solvo** — production environment with hundreds of flows serving hundreds of users: Try/Catch/Finally patterns, Teams notifications with Adaptive Cards, and bulk data processing between Excel and Jira. *Client work under NDA — happy to walk through the patterns and my role in an interview.*
- **n8n + local LLMs** — WhatsApp customer-service bot for a real business, handling 70–150 conversations/day on self-hosted infrastructure (Docker + PostgreSQL).
- **Document AI** — end-to-end pipeline with OCR, classification and routing (Azure AI Builder + Azure OpenAI), including human-in-the-loop review via Teams.
